# Visual assets

The README cover is `banner.png`. It was created with the built-in Imagegen tool and is stored here so the repository can display it directly.

The five badges under `badges/` are editable SVGs. Their mint accent matches the cover. Each badge links to a relevant prompt or README section, and all text is also available through descriptive image alternatives.

## Banner generation prompt

```text
Use case: ads-marketing
Asset type: polished wide GitHub README cover banner, landscape 3:1 aspect ratio, ideally 1536 by 512 pixels.
Primary request: Create a distinctive, professional cover for "Build What Sells", a free collection of three ready-to-use AI prompts for solo SaaS founders and vibe coders. The prompts help find SaaS ideas with real demand, evaluate organic Google traffic, and generate UGC videos.
Style: beautifully art-directed editorial technology illustration with tactile three-dimensional objects, precise typography and generous negative space. Suitable for a developer-facing repository. Understated, confident, useful; not a busy advertising poster.
Composition: a strong title block and a coherent group of three sculptural motifs, arranged to fit this shallow wide banner without crowding. The three motifs represent a small stack of research/evidence cards, a magnifying glass with a search-demand graph, and an upright smartphone with a simple video play symbol. Use these as conceptual illustrations, not screenshots or realistic application UI. Refined material shading, carefully balanced object sizes, subtle surface texture and crisp edges.
Backdrop: clean dark neutral graphite, with light neutral typography and one restrained accent color chosen to suit the illustration. Excellent contrast on both GitHub light and dark pages.
Text, exactly and only: the main title "Build What Sells"; a small supporting line "IDEAS / SEARCH TRAFFIC / UGC". Main title must be large, perfectly spelled, and easily readable when scaled to a README. No fine print.
Constraints: generous safe margins on all sides. No clipped text. No people, hands, rockets, dollar symbols, company logos, fake dashboard data, fake metrics, badges, watermarks or additional copy. The illustration must feel intentionally designed as one composition. Output the final banner itself, no browser frame or mockup.
```
